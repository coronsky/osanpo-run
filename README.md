# コロンアンドムーンのお散歩ラン

MonChien のコロンとムーンが、がけや段差をとびこえておやつを集める横スクロールランゲームです。

**あそぶ: https://coronsky.github.io/osanpo-run/**

- 無料・広告なし・会員登録なし
- モード:スタート(ハート3つ)/エキスパート(2匹タッグ・ハート1つずつ)/今日のチャレンジ
- 遊び方と注意事項は、ゲームのタイトル画面「あそびかた・注意事項」にあります

## このゲームについて

- キャラクターのイラストとタイトル画像は画像生成AIを使って作成しています
- プログラム・背景・効果音・BGMは AI(Claude)の手伝いを受けて制作しています
- イラスト・画像の無断転載や再配布はご遠慮ください
